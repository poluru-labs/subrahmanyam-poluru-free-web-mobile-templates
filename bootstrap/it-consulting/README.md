## 📝 Customization

### Colors
The main brand colors are defined in the CSS file:
- Primary: `#ff914d` (Orange)
- Secondary: `#2c3e50` (Dark Blue)
- Background: `#f8f9fa` (Light Gray)

### Content
All content uses Lorem Ipsum placeholder text. Replace with your actual content:
- Company information
- Service descriptions
- Team member details
- Contact information

### Images
Replace the placeholder images with your own:
- Logo/Brand text
- Hero background image
- Team member photos
- Service icons
- Thanks to Freepik.com [[https://freepik.com]]

## 🔧 CSS Classes

All custom CSS classes use the `ftpl-` prefix to avoid conflicts:
- `.ftpl-service-card` - Service card styling
- `.ftpl-content-img` - Hero section backgrounds
- `.ftpl-text-logo` - Text-based logo styling
- `.ftpl-breadcrumb` - Navigation breadcrumbs
