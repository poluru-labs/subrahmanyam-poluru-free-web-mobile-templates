# AI Meal Planner

Build weekly menus around preferences, macros, and leftovers.

Modern React template with light/dark themes, SCSS modules, and an AI workspace shell.

**Brand color:** `#FF6600`  
**Author:** [Subrahmanyam Poluru](https://polurus.com)


## Quick start

```bash
npm install
cp .env.example .env
npm run dev
```
