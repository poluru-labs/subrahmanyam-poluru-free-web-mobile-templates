# AI Receipt Organizer

Capture receipts, categorize spend, and prepare exports.

Modern React template with light/dark themes, SCSS modules, and an AI workspace shell.

**Brand color:** `#59253A`  
**Author:** [Subrahmanyam Poluru](https://polurus.com)


## Quick start

```bash
npm install
cp .env.example .env
npm run dev
```
