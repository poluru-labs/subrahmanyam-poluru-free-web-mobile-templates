# AI Transcription Workspace

Transcribe, clean, and structure audio into usable text.

Modern React template with light/dark themes, SCSS modules, and an AI workspace shell.

**Brand color:** `#892B2B`  
**Author:** [Subrahmanyam Poluru](https://polurus.com)


## Quick start

```bash
npm install
cp .env.example .env
npm run dev
```
