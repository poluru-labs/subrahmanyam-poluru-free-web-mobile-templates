# Jobsdora — Enterprise Job Portal

Premium hiring platform template built with **HTML**, **CSS**, **JavaScript**, **Bootstrap 5**, **Bootstrap Icons**, and **Google Fonts (Manrope)**.

Brand primary: `#FF0052`

## Features

- Sticky navbar with smooth scrolling
- Hero with job search, filters, and CTAs
- Featured jobs, categories, and employer showcase
- Candidate benefits + application process steps
- Animated hiring stats on scroll
- Testimonials and recruiter CTA
- Candidate / Employer tabbed views
- Accessible, responsive layout

## Setup

```bash
npm install
npm run dev
```

Optional design-system dependency is included for Poluru Labs alignment:

```bash
npm i @poluru-labs/enterprise-design-system-react
```
