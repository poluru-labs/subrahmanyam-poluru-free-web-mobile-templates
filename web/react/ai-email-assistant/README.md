# AI Email Assistant

Draft, triage, and personalize email without losing your voice.

Modern React template with light/dark themes, SCSS modules, and an AI workspace shell.

**Brand color:** `#AA2B1D`  
**Author:** [Subrahmanyam Poluru](https://polurus.com)


## Quick start

```bash
npm install
cp .env.example .env
npm run dev
```
