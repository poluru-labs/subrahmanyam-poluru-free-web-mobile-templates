# AI Contract Review Workspace

Flag risks, obligations, and unusual clauses in contracts.

Modern React template with light/dark themes, SCSS modules, and an AI workspace shell.

**Brand color:** `#F2A900`  
**Author:** [Subrahmanyam Poluru](https://polurus.com)


## Quick start

```bash
npm install
cp .env.example .env
npm run dev
```
