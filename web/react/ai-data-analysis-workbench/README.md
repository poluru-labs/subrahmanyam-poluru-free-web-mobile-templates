# AI Data Analysis Workbench

Ask questions of datasets and get charts with explanations.

Modern React template with light/dark themes, SCSS modules, and an AI workspace shell.

**Brand color:** `#9E4F20`  
**Author:** [Subrahmanyam Poluru](https://polurus.com)


## Quick start

```bash
npm install
cp .env.example .env
npm run dev
```
