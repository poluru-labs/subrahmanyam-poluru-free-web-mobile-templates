# AI Quiz Generator

Generate quizzes from notes, PDFs, and lesson plans.

Modern React template with light/dark themes, SCSS modules, and an AI workspace shell.

**Brand color:** `#F7AD45`  
**Author:** [Subrahmanyam Poluru](https://polurus.com)


## Quick start

```bash
npm install
cp .env.example .env
npm run dev
```
