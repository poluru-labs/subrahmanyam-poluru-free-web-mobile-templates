# Keyline — Car rental marketplace (Tailwind)

Single-page marketplace demo for fictional **Harbor Mobility** hosts and airport desks.

- **Stack:** Tailwind CSS v4 (browser), Bootstrap Icons, vanilla JS
- **Fonts:** Roboto (display), Lato (UI labels), Open Sans (body) via Google Fonts
- **Brand:** `#F4CE14` with ink `#1A1810` for readable buttons and text (no gradients)
- **Prefix:** `cr-*` in supplemental CSS

## Run locally

From the repository root:

```bash
python3 -m http.server 8080
```

Open `http://localhost:8080/web/tailwind/car-rental-marketplace/`

## Demo behavior

- Hero **Search fleet** scrolls to listings and shows a toast (no API)
- Class filters and search on the fleet grid
- **Hold** and favorites (localStorage when available)
- Contact form is browser-only
