# Commonroom — Community discussion forum (Tailwind)

Fictional Austin forum demo: topic filters, saved threads, and local draft posts.

**Brand:** `#281C59` · **Fonts:** Roboto, Lato, Open Sans

## Preview

From the repository root:

```bash
python3 -m http.server 8775
```

Open: `http://127.0.0.1:8775/web/tailwind/community-discussion-forum/`
