# Poluru Track — Logistics shipment tracker

Clean, light-themed logistics portal template for tracking shipments, reviewing hub metrics, and booking demo loads.

## Brand

- Primary: `#0046FF`
- Soft tint: `#e8efff`
- Fonts: Roboto (headings), Lato (nav, labels), Open Sans (body)

## Preview

Open `index.html` in a browser, or serve the folder locally:

```bash
python3 -m http.server 8080
```

Then visit `http://localhost:8080`.

## Features

- Sticky header with mobile menu
- Hero tracking lookup (synced with table/resource search)
- Shipment board with status filters and CSV export
- Hub capacity cards (flat progress bars, no gradients)
- Resource guides and new-shipment demo forms (localStorage only)
- Footer with author **Subrahmanyam Poluru** and [portfolio](https://polurus.com)
