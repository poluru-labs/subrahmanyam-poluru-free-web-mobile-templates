# Poluru Tickets

A responsive, standalone **event ticketing platform** template for browsing events, venues, and a demo cart flow.

## Preview

Open `index.html` directly, or run `python3 -m http.server 8080` from this folder and visit `http://localhost:8080/`.

## Customize

- `index.html`: events, venues, navigation, and organizer CTA.
- `assets/css/style.css`: layout and ticketing styling; Google Fonts **Roboto**, **Lato**, and **Open Sans**.
- `assets/js/script.js`: search, filters, favorites, cart, dialogs, and mobile menu.
- Brand color: `#BD114A`. Supporting tint: `#fceef3`.

Each folder is self-contained. No install or build is required. Fonts load from Google Fonts; event photos load from Unsplash when online.

## Demo behavior

All events, venues, and prices are fictional. Cart and favorites use localStorage in this browser only. Checkout and organizer forms save demo requests locally; no payments or real tickets are issued. Search and category filters work on event cards. There is no backend or payment processor.
