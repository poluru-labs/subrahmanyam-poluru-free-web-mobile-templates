# Poluru Cast — Podcast discovery app

Light-themed podcast discovery template with browse, episodes, curated lists, and a fixed demo player.

## Brand

- Primary: `#273F4F`
- Soft tint: `#e8eef2`
- Fonts: Roboto (headings), Lato (nav, labels), Open Sans (body)

## Preview

Open `index.html` in a browser, or serve the folder locally:

```bash
python3 -m http.server 8080
```

Then visit `http://localhost:8080`.

## Features

- Sticky header with mobile menu and library modal
- Hero search synced with show filters
- Show grid with genre filters and follow hearts
- Episode list with demo audio preview
- Curated playlists and creator cards
- Flat bottom player bar (no gradients)
- Footer with author **Subrahmanyam Poluru** and [portfolio](https://polurus.com)
