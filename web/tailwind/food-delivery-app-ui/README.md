# PlateHarbor — Food delivery app UI (Tailwind v4)

Single-page food delivery product site for **Harbor City**. Brand color **#8E1EA2**, no gradients, Google Fonts **Roboto** (headings), **Lato** (UI), **Open Sans** (body).

## Features

- Sticky navigation with mobile menu and cart badge (`localStorage` count)
- Restaurant grid with cuisine filters, search, favorites, add-to-cart toasts
- How it works, delivery zones, partner signup, FAQ, contact
- Author footer with [polurus.com](https://polurus.com)

## Preview locally

From the repository root:

```bash
python3 -m http.server 8080
```

Open `http://localhost:8080/web/tailwind/food-delivery-app-ui/`
