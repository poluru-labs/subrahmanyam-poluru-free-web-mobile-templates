# Poluru Legal

A responsive, standalone **legal case management** dashboard for matters, clients, deadlines, and a demo kanban board.

## Preview

Open `index.html` directly, or run `python3 -m http.server 8080` from this folder and visit `http://localhost:8080/`.

## Customize

- `index.html`: KPIs, docket table, kanban, clients, and deadlines.
- `assets/css/style.css`: dashboard layout; Google Fonts **Roboto**, **Lato**, and **Open Sans**.
- `assets/js/script.js`: export, search/filters, kanban move, dialogs, and demo forms.
- Brand color: `#41A67E`. Supporting tint: `#e8f5ef`.

Each folder is self-contained. No install or build is required.

## Demo behavior

All clients, matters, and deadlines are fictional. This template is **not** legal advice or a practice management system. New matter forms save demo data in localStorage only. Kanban “Advance” moves cards between columns in the browser. Export downloads CSV from tables. There is no backend or document store.
