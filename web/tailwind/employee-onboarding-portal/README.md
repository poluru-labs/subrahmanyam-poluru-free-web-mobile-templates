# Poluru Onboard

A responsive, standalone **employee onboarding portal** with checklists, resources, team contacts, and a first-30-days timeline.

## Preview

Open `index.html` directly, or run `python3 -m http.server 8080` from this folder and visit `http://localhost:8080/`.

## Customize

- `index.html`: welcome content, checklist tasks, resources, and team cards.
- `assets/css/style.css`: layout and onboarding styling; Google Fonts **Roboto**, **Lato**, and **Open Sans**.
- `assets/js/script.js`: checklist progress (localStorage), search/filters, dialogs, and mobile menu.
- Brand color: `#FF8C00`. Supporting tint: `#fff4e8`.

Each folder is self-contained. No install or build is required. Fonts load from Google Fonts; hero imagery loads from Unsplash when online.

## Demo behavior

All names, dates, and policies are fictional. Checklist completion saves in this browser via localStorage. Resource and HR dialogs show sample content; forms save demo messages locally only. Search and filters work on resource cards. There is no backend, SSO, or HRIS integration.
