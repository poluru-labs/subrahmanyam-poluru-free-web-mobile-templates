# Workbay — Coworking space booking (Tailwind)

Single-page booking demo for fictional **Harbor Studios** locations.

- **Stack:** Tailwind CSS v4 (browser), Bootstrap Icons, vanilla JS
- **Fonts:** Roboto (display), Lato (UI), Open Sans (body) via Google Fonts
- **Brand:** `#8D0B41` (no gradients)
- **Prefix:** `cw-*` in supplemental CSS

## Run locally

From the repository root:

```bash
python3 -m http.server 8080
```

Open `http://localhost:8080/web/tailwind/coworking-space-booking/`

## Demo behavior

- Hero **Find a desk** scrolls to the space grid
- Type filters, search, bookmarks (localStorage when available)
- **Book** and tour/contact forms show toasts only
