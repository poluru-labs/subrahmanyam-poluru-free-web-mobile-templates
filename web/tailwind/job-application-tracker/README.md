# Folio

A responsive job-application tracker. Filter a sample board, move a role between stages, and add a follow-up that stays in the browser.

## Preview

Open `index.html` directly, or run `python3 -m http.server 8080` from this folder.

## Customize

- `index.html`: page structure and sample copy.
- `assets/css/style.css`: focus, motion, and the headline underline.
- `assets/js/script.js`: the board, filters, and the add form. Sample roles live in the script.
- Brand color: `#E94560`. Fonts: Roboto and Lato.

No install step. Tailwind loads in the browser. Internet access is needed for Tailwind, icons, and Google Fonts.

## Demo behavior

Companies, stages, and dates are fictional. Added roles are saved in this browser only and are not sent. Restore sample clears them.
