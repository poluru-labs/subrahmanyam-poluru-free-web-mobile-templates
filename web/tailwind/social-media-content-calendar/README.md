# Poluru Plan — Social media content calendar

Sidebar workspace for scheduling posts, viewing the week, and managing channel content—demo data only.

## Brand

- Primary: `#FE0000`
- Soft tint: `#ffe8e8`
- Fonts: Roboto (headings), Lato (nav, labels), Open Sans (body)

## Preview

Open `index.html` in a browser, or serve the folder locally:

```bash
python3 -m http.server 8080
```

Then visit `http://localhost:8080`.

## Features

- Sidebar navigation and KPI overview
- Flat bar chart and channel mix progress bars (no gradient fills)
- Seven-day calendar strip and post queue table with channel filters
- Kanban board with advance action
- Connected channel cards
- Footer with author **Subrahmanyam Poluru** and [portfolio](https://polurus.com)
