# Poluru Assets

A responsive, standalone **digital asset marketplace** template for browsing UI kits, icons, templates, and illustrations.

## Preview

Open `index.html` directly, or run `python3 -m http.server 8080` from this folder and visit `http://localhost:8080/`.

## Customize

- `index.html`: marketplace content, asset cards, creators, and pricing.
- `assets/css/style.css`: layout and marketplace styling; Google Fonts **Roboto**, **Lato**, and **Open Sans**.
- `assets/js/script.js`: search, filters, favorites, cart, dialogs, and mobile menu.
- Brand color: `#E87F24`. Supporting tint: `#fef3eb`.

Each folder is self-contained. No install or build is required. Fonts load from Google Fonts; preview images load from Unsplash. Internet access is needed for those assets.

## Demo behavior

All assets, creators, prices, and stats are fictional. Cart and favorites use localStorage in this browser only. Forms save demo seller inquiries locally; no payments, downloads, or accounts are connected. Search and category filters work on asset cards via `data-search` / `data-category`. There is no backend or live marketplace.
