# TrainHarbor — Personal trainer booking (Tailwind v4)

Clean, gradient-free landing page for a fictional trainer booking app. Brand color **#007DCC**.

## Fonts

- **Roboto** — headings  
- **Lato** — UI / labels  
- **Open Sans** — body  

## Features

- Sticky utility bar + navigation with mobile menu  
- Coach grid with specialty filters (Strength, Endurance, Mobility)  
- Favorites and booking count (`localStorage`)  
- Interactive scheduler with time-slot selection  
- Plans, studio info, FAQ, contact form, toasts  
- Author footer with [polurus.com](https://polurus.com) and **mail.polurus@gmail.com**

## Preview locally

From the repository root:

```bash
python3 -m http.server 8080
```

Open: `http://127.0.0.1:8080/web/tailwind/personal-trainer-booking/`

## Files

| File | Purpose |
|------|---------|
| `index.html` | Page structure, Tailwind `@theme`, content |
| `assets/css/style.css` | Grid, slots, toast, reveal |
| `assets/js/script.js` | Filters, booking, favorites |
