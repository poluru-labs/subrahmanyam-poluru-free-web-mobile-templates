# Poluru Give — Nonprofit donation platform

Light-themed donation portal for browsing campaigns, tracking impact, and saving demo pledges locally.

## Brand

- Primary: `#309898`
- Soft tint: `#e6f5f5`
- Fonts: Roboto (headings), Lato (nav, labels), Open Sans (body)

## Preview

Open `index.html` in a browser, or serve the folder locally:

```bash
python3 -m http.server 8080
```

Then visit `http://localhost:8080`.

## Features

- Sticky header with mobile menu and giving summary
- Hero search synced with campaign filters
- Campaign grid with cause filters, favorites, and flat funding bars
- Impact metrics and transparency table (CSV export)
- Demo donate / monthly / matching forms (localStorage only)
- Footer with author **Subrahmanyam Poluru** and [portfolio](https://polurus.com)
