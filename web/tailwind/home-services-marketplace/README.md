# Poluru Home

A responsive, standalone **home services marketplace** for browsing categories, booking local pros, and demo signup flows.

## Preview

Open `index.html` directly, or run `python3 -m http.server 8080` from this folder and visit `http://localhost:8080/`.

## Customize

- `index.html`: service cards, top pros, pricing, and navigation.
- `assets/css/style.css`: layout and marketplace styling; Google Fonts **Roboto**, **Lato**, and **Open Sans**.
- `assets/js/script.js`: search, filters, favorites, dialogs, and mobile menu.
- Brand color: `#00B7CD`. Supporting tint: `#e8fafa`.

Each folder is self-contained. No install or build is required. Fonts load from Google Fonts; service photos load from Unsplash when online.

## Demo behavior

All pros, prices, and reviews are fictional. Booking and pro signup forms save demo requests in localStorage only; no payments or job dispatch occur. Search and category filters work on service cards. There is no backend or live marketplace.
