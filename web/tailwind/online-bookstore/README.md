# BookHarbor — Online bookstore (Tailwind v4)

Clean, gradient-free landing page for a fictional online bookstore. Brand color **#007DCC**.

## Fonts

- **Roboto** — headings  
- **Lato** — UI / labels  
- **Open Sans** — body  

## Features

- Sticky utility bar + navigation with mobile menu  
- Hero search that scrolls to the catalog  
- Genre filters (All, Fiction, Nonfiction, Kids) + live search  
- Wishlist and cart demo (`localStorage`)  
- Membership, events, FAQ, contact, newsletter sections  
- Author footer with [polurus.com](https://polurus.com) and **mail.polurus@gmail.com**

## Preview locally

From the repository root:

```bash
python3 -m http.server 8080
```

Open: `http://127.0.0.1:8080/web/tailwind/online-bookstore/`

## Files

| File | Purpose |
|------|---------|
| `index.html` | Page structure, Tailwind `@theme`, content |
| `assets/css/style.css` | Grid, toast, reveal, skip link |
| `assets/js/script.js` | Filters, cart, wishlist, toasts |
| `assets/favicon.svg` | Brand icon |
