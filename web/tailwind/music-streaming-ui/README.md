# WaveHarbor — Music streaming UI (Tailwind v4)

Single-page music streaming product site for **Harbor Audio**. Brand color **#FFCED8**, no gradients, Google Fonts **Roboto** (headings), **Lato** (UI), **Open Sans** (body).

## Features

- Sticky navigation with mobile menu
- **Mix catalog** with mood filters, search, favorites (localStorage)
- Fixed **player bar** with optional low-volume ambient demo (Web Audio)
- Artists, pricing, signup, FAQ, contact
- Author footer with [polurus.com](https://polurus.com)

## Preview locally

From the repository root:

```bash
python3 -m http.server 8080
```

Open `http://localhost:8080/web/tailwind/music-streaming-ui/`
