# Poluru Depot

A responsive, standalone **warehouse operations dashboard** with inventory, orders, pick-wave kanban, throughput chart, alerts, and shift safety checklist.

## Preview

Open `index.html` directly, or run `python3 -m http.server 8080` from `codeex-themes/warehouse-operations-dashboard` and visit `http://localhost:8080/`.

## Customize

- `index.html`: stats, tables, kanban, sidebar nav, brand tokens.
- `assets/css/style.css`: dashboard layout; Google Fonts **Roboto**, **Lato**, and **Open Sans**.
- `assets/js/script.js`: search, order filters, chart period, kanban moves, safety checklist, modals, CSV export.
- Brand color: `#6B011F`. Soft tint: `#f5e8ec`. Primary button text: `#ffffff`.

Each folder is self-contained. No install or build is required.

## Demo behavior

All SKUs, orders, waves, and metrics are fictional. Safety checks and demo forms persist in this browser (`localStorage` keys prefixed with `poluru:warehouse-operations-dashboard:`). Not connected to WMS, ERP, or carrier systems.
