# Subra Studio

A responsive, standalone freelancer invoicing template.

## Preview

Open `index.html` directly, or run `python3 -m http.server 8080` from the collection root and visit `http://localhost:8080/freelancer-invoicing/`.

## Customize

- `index.html`: content, brand colors, sample people, and page structure.
- `assets/css/style.css`: responsive layouts; Google Fonts Roboto and Open Sans.
- `assets/js/script.js`: accessible dialogs and relevant template interactions.
- Brand color: `#8c4269`. Supporting color: `#f8edf3`.

Each folder is self-contained and can be copied independently. No install or build is needed. Fonts load from Google Fonts; photography loads from Unsplash. Internet access is needed for those assets. Layouts use CSS, with no runtime framework or CDN JavaScript dependency.

## Demo behavior

All people, metrics, products, and examples are fictional. Forms explicitly save demo requests only in this browser and do not send email, book appointments, or take payments. Favorites, shopping checks, habit checks, journal entries, and reply drafts use localStorage where relevant. Invoice totals are calculated live and can be printed to PDF. Reports download as CSV. The music template plays a quiet synthesized ambient preview, not licensed tracks. Other changes last for the current visit. There is no backend, authentication, payment processor, or live data feed.
