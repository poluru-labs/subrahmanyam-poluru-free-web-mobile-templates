# Poluru Stock

A responsive, standalone **inventory management dashboard** for SKUs, warehouses, stock health, and alerts.

## Preview

Open `index.html` directly, or run `python3 -m http.server 8080` from this folder and visit `http://localhost:8080/`.

## Customize

- `index.html`: KPIs, charts, stock table, warehouses, and alerts.
- `assets/css/style.css`: dashboard layout; Google Fonts **Roboto**, **Lato**, and **Open Sans**.
- `assets/js/script.js`: chart period toggle, CSV export, search/filters, and dialogs.
- Brand color: `#161E54`. Supporting tint: `#e8eaf3`.

Each folder is self-contained. No install or build is required.

## Demo behavior

All SKUs, warehouses, and metrics are fictional. Export downloads CSV from visible tables. Restock forms save demo requests in localStorage only. Search and category filters apply to stock table rows. There is no backend or WMS integration.
