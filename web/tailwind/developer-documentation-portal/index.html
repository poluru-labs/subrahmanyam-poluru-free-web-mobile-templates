Quick start Node.js

const client = new PoluruClient({
  apiKey: process.env.POLURU_API_KEY,
});

const profile = await client.users.me();
console.log(profile.id, profile.email);

API REFERENCE

Endpoints at a glance.

REST resources with consistent naming, versioning, and JSON responses.

Method Endpoint Description Scope
GET /v2/users/me Return the authenticated user profile read
POST /v2/projects Create a new project workspace write
GET /v2/projects/:id Fetch project details and settings read
PATCH /v2/projects/:id Update project metadata write
POST /v2/webhooks Register an HTTPS webhook endpoint admin
Example request curl 
curl -X GET "https://api.poluru.dev/v2/users/me" \
  -H "Authorization: Bearer YOUR_API_KEY" \
  -H "Accept: application/json"
