# Poluru DevDocs

A responsive, standalone **developer documentation portal** template with guides, API reference, SDK cards, and changelog.

## Preview

Open `index.html` directly, or run `python3 -m http.server 8080` from this folder and visit `http://localhost:8080/`.

## Customize

- `index.html`: content, navigation, endpoints, and page structure.
- `assets/css/style.css`: layout and docs-specific styling; Google Fonts **Roboto**, **Lato**, and **Open Sans**.
- `assets/js/script.js`: search, filters, dialogs, code copy, and mobile menu.
- Brand color: `#1B4EF5`. Supporting tint: `#eef2fe`.

Each folder is self-contained. No install or build is required. Fonts load from Google Fonts. Internet access is needed for fonts.

## Demo behavior

All API names, endpoints, and metrics are fictional. Forms save demo requests only in this browser and do not send email or issue real API keys. Guide and SDK modals show sample content. Code copy uses the clipboard API when available. Search and category filters work on guide cards via `data-search` / `data-category`. There is no backend or live API.
