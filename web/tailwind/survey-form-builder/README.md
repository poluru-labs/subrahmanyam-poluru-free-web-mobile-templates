# Poluru Forms — Survey form builder

Light-themed survey builder template with form preview, question palette, and response table (demo data).

## Brand

- Primary: `#EB455F`
- Soft tint: `#fceef1`
- Fonts: Roboto (headings), Lato (nav, labels), Open Sans (body)

## Preview

Open `index.html` in a browser, or serve the folder locally:

```bash
python3 -m http.server 8080
```

Then visit `http://localhost:8080`.

## Features

- Sticky header with mobile menu
- Hero search synced with survey type filters
- Survey cards, builder canvas, responses table
- Template library and publish/share modals (localStorage demo)
- Footer with author **Subrahmanyam Poluru** and [portfolio](https://polurus.com)
