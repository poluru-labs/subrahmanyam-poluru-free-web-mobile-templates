# Poluru Care

A responsive, standalone **healthcare appointment portal** for finding providers, viewing locations, and demo booking flows.

## Preview

Open `index.html` directly, or run `python3 -m http.server 8080` from this folder and visit `http://localhost:8080/`.

## Customize

- `index.html`: providers, locations, visit summaries, and navigation.
- `assets/css/style.css`: layout and portal styling; Google Fonts **Roboto**, **Lato**, and **Open Sans**.
- `assets/js/script.js`: search, filters, dialogs, mobile menu, and demo appointment storage.
- Brand color: `#30497D`. Supporting tint: `#eef2f7`.

Each folder is self-contained. No install or build is required. Fonts load from Google Fonts; clinic imagery loads from Unsplash when online.

## Demo behavior

All providers, locations, and appointments are fictional. This template is **not** a medical service and does not handle emergencies. Booking forms save demo requests in localStorage only; no data is sent to a clinic or EHR. Search and specialty filters work on provider cards. There is no backend or live scheduling.
