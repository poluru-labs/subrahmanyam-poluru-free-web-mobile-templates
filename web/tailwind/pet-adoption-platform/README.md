# Pawlane — Pet adoption platform (Tailwind v4)

Clean, gradient-free landing page for a fictional pet adoption app. Brand color **#FFC349**.

## Fonts

- **Roboto** — headings
- **Lato** — UI / labels
- **Open Sans** — body

## Features

- Sticky utility bar and navigation with a mobile menu
- Companion grid with species filters, search, and saved-only view
- Favorites and meet requests stored in `localStorage`
- How adoption works, visit hours, stories, FAQ, and contact
- Author footer with [polurus.com](https://polurus.com) and **mail.polurus@gmail.com**

## Preview locally

From the repository root:

```bash
python3 -m http.server 8080
```

Open: `http://127.0.0.1:8080/web/tailwind/pet-adoption-platform/`

## Files

| File | Purpose |
|------|---------|
| `index.html` | Page structure, Tailwind `@theme`, content |
| `assets/css/style.css` | Grid, toast, reveal, mobile nav |
| `assets/js/script.js` | Filters, favorites, meet requests |
