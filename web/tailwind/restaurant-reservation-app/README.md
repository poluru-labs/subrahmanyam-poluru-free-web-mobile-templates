# Poluru Table — Restaurant reservation app

Light-themed restaurant discovery and table booking template with demo reservations stored locally.

## Brand

- Primary: `#DC0083`
- Soft tint: `#fceef6`
- Fonts: Roboto (headings), Lato (nav, labels), Open Sans (body)

## Preview

Open `index.html` in a browser, or serve the folder locally:

```bash
python3 -m http.server 8080
```

Then visit `http://localhost:8080`.

## Features

- Sticky header with mobile menu
- Hero search + quick-book panel
- Restaurant grid with cuisine filters and saved hearts
- Tonight’s time slots (flat buttons, no gradients)
- Experiences and support CTAs
- Footer with author **Subrahmanyam Poluru** and [portfolio](https://polurus.com)
