# Stackforge — Coding bootcamp landing (Tailwind)

Single-page landing for fictional **Harbor Labs** cohorts and career programs.

- **Stack:** Tailwind CSS v4 (browser), Bootstrap Icons, vanilla JS
- **Fonts:** Roboto (display), Lato (UI), Open Sans (body) via Google Fonts
- **Brand:** `#FFD369` with ink `#1A1814` (no gradients)
- **Prefix:** `cb-*` in supplemental CSS

## Run locally

From the repository root:

```bash
python3 -m http.server 8080
```

Open `http://localhost:8080/web/tailwind/coding-bootcamp-landing/`

## Demo behavior

- Program level filters and search
- **View syllabus** opens a sample module list
- Bookmark programs (localStorage when available)
- Apply and contact forms are browser-only
