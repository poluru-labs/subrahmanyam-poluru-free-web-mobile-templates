FAQ

Before you say yes

Is Vowline a live booking site?

No. This is a front-end demo. Saved looks and inquiries stay in local storage.

Do you plan real weddings from this page?

There is no calendar, contract, or payment flow. Copy and photos are fictional samples.

What happens when I save a celebration?

The id is stored in this browser. Use Saved only beside search to review your list.

Are package prices final?

Amounts are placeholder labels for layout only, not quotes.
