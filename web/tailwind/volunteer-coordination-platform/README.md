# Poluru Serve

A responsive, standalone **volunteer coordination platform** template with opportunities, shift calendar, team roster, onboarding checklist, and demo signups.

## Preview

Open `index.html` directly, or run `python3 -m http.server 8080` from `codeex-themes/volunteer-coordination-platform` and visit `http://localhost:8080/`.

## Customize

- `index.html`: opportunities, shifts table, teams, brand tokens, and structure.
- `assets/css/style.css`: layout and theme styles; Google Fonts **Roboto**, **Lato**, and **Open Sans**.
- `assets/js/script.js`: search, filters, dialogs, signups, favorites, onboarding checks, and CSV export.
- Brand color: `#EE5007`. Soft tint: `#fdeee6`. Primary button text: `#ffffff`.

Each folder is self-contained and can be copied independently. No install or build is needed. Fonts load from Google Fonts; photography loads from Unsplash. Internet access is needed for those assets.

## Demo behavior

All organizations, shifts, and metrics are fictional. Signups and requests save only in this browser (`localStorage` keys prefixed with `poluru:volunteer-coordination-platform:`). No email, background checks, or live scheduling.
