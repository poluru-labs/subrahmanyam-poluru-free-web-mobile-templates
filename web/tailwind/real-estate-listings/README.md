# Poluru Homes — Real estate listings

Light-themed property listings template with buy/rent filters, neighborhood guides, and demo tour requests.

## Brand

- Primary: `#8FD14F`
- Soft tint: `#eef8e8`
- Button text on primary: `#152118` (contrast)
- Fonts: Roboto (headings), Lato (nav, labels), Open Sans (body)

## Preview

Open `index.html` in a browser, or serve the folder locally:

```bash
python3 -m http.server 8080
```

Then visit `http://localhost:8080`.

## Features

- Sticky header with mobile menu
- Hero search synced with listing filters
- Property grid (Buy / Rent / New build), saved hearts, detail & tour modals
- Neighborhood guides and agent cards
- Sell-with-us CTAs (localStorage demo forms)
- Footer with author **Subrahmanyam Poluru** and [portfolio](https://polurus.com)
