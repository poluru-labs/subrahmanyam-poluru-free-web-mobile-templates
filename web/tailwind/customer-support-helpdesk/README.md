# CaseHarbor — Customer support helpdesk (Tailwind v4)

Single-page helpdesk product site for **Harbor SaaS**. Brand color **#DE7272**, no gradients, Google Fonts **Roboto** (headings), **Lato** (UI), **Open Sans** (body).

## Features

- Sticky navigation with mobile menu
- Demo shared inbox: status filters, search, open-thread dialog, assign toasts
- Channels, automation, pricing, trial signup, FAQ, contact
- Author footer with [polurus.com](https://polurus.com)

## Preview locally

From the repository root:

```bash
python3 -m http.server 8080
```

Open `http://localhost:8080/web/tailwind/customer-support-helpdesk/`
