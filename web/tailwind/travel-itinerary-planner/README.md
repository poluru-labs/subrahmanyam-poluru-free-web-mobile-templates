# Poluru Trips

A responsive, standalone **travel itinerary planner** website template with trip cards, day timeline, destination guides, and a pack checklist.

## Preview

Open `index.html` directly, or run `python3 -m http.server 8080` from `codeex-themes/travel-itinerary-planner` and visit `http://localhost:8080/`.

## Customize

- `index.html`: trips, timeline blocks, guides, brand tokens, and structure.
- `assets/css/style.css`: layout and theme styles; Google Fonts **Roboto**, **Lato**, and **Open Sans**.
- `assets/js/script.js`: search, filters, dialogs, favorites, pack list, and demo trip forms.
- Brand color: `#FFDE00`. Soft background tint: `#fff9d6`. Button text on brand: `#152118`.

Each folder is self-contained and can be copied independently. No install or build is needed. Fonts load from Google Fonts; photography loads from Unsplash. Internet access is needed for those assets.

## Demo behavior

All trips, flights, hotels, and guides are fictional. Forms save demo data only in this browser (`localStorage` keys prefixed with `poluru:travel-itinerary-planner:`). Nothing is sent to booking systems or email. Favorites, pack checks, planned trips, and activities persist locally where storage is available.
