# Poluru Claims

A responsive, standalone **insurance claims portal** for tracking claims, filing new ones, and browsing member guides.

## Preview

Open `index.html` directly, or run `python3 -m http.server 8080` from this folder and visit `http://localhost:8080/`.

## Customize

- `index.html`: claim table, timeline, guides, and file-claim entry points.
- `assets/css/style.css`: layout and portal styling; Google Fonts **Roboto**, **Lato**, and **Open Sans**.
- `assets/js/script.js`: filters, dialogs, CSV export, mobile menu, and demo forms.
- Brand color: `#077A7D`. Supporting tint: `#e6f3f3`.

Each folder is self-contained. No install or build is required.

## Demo behavior

All claims, policies, and adjuster names are fictional. This is **not** insurance coverage or emergency service. Forms save demo requests in localStorage only. Claim search shows a toast and filters visible rows. Export downloads CSV from the claims table. There is no backend or carrier integration.
