# BillHarbor — Invoice generator SaaS (Tailwind v4)

Single-page invoice product site for **Harbor Freelancers**. Brand color **#363199**, no gradients, Google Fonts **Roboto** (headings), **Lato** (UI), **Open Sans** (body).

## Features

- Sticky navigation with mobile menu
- **Live invoice editor**: line items, tax, add/remove rows, auto totals
- Print / Save PDF via browser print styles (invoice panel only)
- Pricing, signup, FAQ, contact (demo toasts)
- Author footer with [polurus.com](https://polurus.com)

## Preview locally

From the repository root:

```bash
python3 -m http.server 8080
```

Open `http://localhost:8080/web/tailwind/invoice-generator-saas/`
