# Whitmore Academy · Parent Portal

Responsive school parent dashboard built with **React**, **Vite**, **Tailwind CSS**, **Google Fonts** (DM Sans + Playfair Display), and **Bootstrap Icons**.

Primary brand color: `#760031`.

## Setup

```bash
npm install
npm run dev
```

Open the URL Vite prints (default `http://localhost:5173`).

| Command | Description |
| --- | --- |
| `npm run dev` | Start the Vite dev server |
| `npm run build` | Production build |
| `npm run preview` | Preview the production build |
