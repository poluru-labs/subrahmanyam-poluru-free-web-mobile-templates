# MealHarbor — Meal planner dashboard (Tailwind v4)

Single-page meal planning product site for **Harbor Households**. Brand color **#FF0000**, no gradients, Google Fonts **Roboto** (headings), **Lato** (UI), **Open Sans** (body).

## Features

- Sticky navigation with mobile menu
- **Weekly meal grid** with swap meal demo (title + image toggle)
- **Grocery list** with localStorage checkboxes and progress count
- Pricing, signup, FAQ, contact (demo toasts)
- Author footer with [polurus.com](https://polurus.com)

## Preview locally

From the repository root:

```bash
python3 -m http.server 8080
```

Open `http://localhost:8080/web/tailwind/meal-planner-dashboard/`
