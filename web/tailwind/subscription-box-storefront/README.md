# BoxHarbor — Subscription box storefront (Tailwind v4)

Clean, gradient-free landing page for a fictional subscription box shop. Brand color **#000080** (navy).

## Fonts

- **Roboto** — headings  
- **Lato** — UI / labels  
- **Open Sans** — body  

## Features

- Sticky utility bar + navigation with mobile menu  
- Six subscription boxes with category filters and search  
- Watchlist and cart demo (`localStorage`)  
- Customize preferences, gift form, testimonials, FAQ, contact  
- Author footer with [polurus.com](https://polurus.com) and **mail.polurus@gmail.com**

## Preview locally

From the repository root:

```bash
python3 -m http.server 8080
```

Open: `http://127.0.0.1:8080/web/tailwind/subscription-box-storefront/`

## Files

| File | Purpose |
|------|---------|
| `index.html` | Page structure, Tailwind `@theme`, content |
| `assets/css/style.css` | Grid, toast, reveal |
| `assets/js/script.js` | Filters, cart, watchlist |
| `assets/favicon.svg` | Brand icon |
