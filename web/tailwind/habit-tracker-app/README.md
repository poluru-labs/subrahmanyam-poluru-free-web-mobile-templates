# StreakHarbor — Habit tracker app (Tailwind v4)

Single-page habit tracker product site for **Harbor Households**. Brand color **#B8892D**, no gradients, Google Fonts **Roboto** (headings), **Lato** (UI), **Open Sans** (body).

## Features

- Sticky navigation with mobile menu
- Interactive **weekly habit grid** (localStorage)
- Solid progress bar and completion counts
- Journal note saved in browser
- Routines, pricing, signup, FAQ, contact
- Author footer with [polurus.com](https://polurus.com)

## Preview locally

From the repository root:

```bash
python3 -m http.server 8080
```

Open `http://localhost:8080/web/tailwind/habit-tracker-app/`
