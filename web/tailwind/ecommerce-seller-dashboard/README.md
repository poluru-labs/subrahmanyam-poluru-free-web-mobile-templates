# Poluru Seller

A responsive, standalone **ecommerce seller dashboard** for tracking sales, orders, products, and customers.

## Preview

Open `index.html` directly, or run `python3 -m http.server 8080` from this folder and visit `http://localhost:8080/`.

## Customize

- `index.html`: sidebar navigation, KPI cards, charts, and tables.
- `assets/css/style.css`: dashboard layout; Google Fonts **Roboto**, **Lato**, and **Open Sans**.
- `assets/js/script.js`: chart period toggle, CSV export, product search/filters, and order dialogs.
- Brand color: `#1B4EF5`. Supporting tint: `#eef2fe`.

Each folder is self-contained. No install or build is required. Product thumbnails load from Unsplash when online.

## Demo behavior

All metrics, orders, and customers are fictional. Export downloads a CSV from visible table data. Product filters use `data-search` / `data-category` on table rows. Chart bars update when changing the period select. Forms in dialogs save demo data locally only. There is no backend, payment processor, or live store connection.
