Routes

/ Dashboard, /members, /trainers, /classes, /checkins, /memberships, plus /about, /docs, and /contact.

CSS prefix

Custom classes use gxd-. Theme tokens sit on :root in src/styles.css.

--gxd-primary: #ff5a5a; --gxd-ink: #161311; --gxd-canvas: #f3efe8;

Filters

Member, trainer, and class lists filter in the page component from src/app/core/data.ts. Keep plan, focus, studio, and status values aligned with the filter selects.

Run locally

cd web/angular/gym-dashboard npm install npm start
