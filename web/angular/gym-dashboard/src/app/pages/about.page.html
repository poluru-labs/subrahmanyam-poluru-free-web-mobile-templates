About Forge Athletic

An Angular gym operations dashboard for club managers: members, trainers, classes, check-ins, and memberships.

What it’s for

Forge is a demo of a downtown club desk. Use it as a starting point for a gym CRM, class booking board, or front-desk kiosk. Copy lives in page components; tokens live in src/styles.css under the gxd- prefix.

Built with Angular, Bootstrap 5, Bootstrap Icons, Barlow, and a small toast service for filters, the check-in form, and feedback.
