Getting started

MentorLoop is a static multi-page Bootstrap template. Serve the folder with any static server:

cd web/bootstrap/mentorloop python3 -m http.server 8000

Open http://localhost:8000. No build step is required.

Theme tokens

Brand colors live on :root in assets/css/style.css:

TokenValueUse
--mlp-primary#0F766ETeal brand, CTAs, links
--mlp-accent#C2410CSecondary emphasis actions
--mlp-ink#0B1220Headers, footer, type
--mlp-canvas#F1F5F9Page background

Typography uses Outfit from Google Fonts.

Key classes

  • .mlp-navbar / .mlp-toggler — sticky nav with mobile collapse
  • .mlp-hero / .mlp-page-hero — landing vs inner page headers
  • .mlp-panel / .mlp-profile — interactive profile surfaces
  • .mlp-toolbar — search + filter row
  • .mlp-wizard-chip / [data-wizard-pane] — matching steps
  • .mlp-docs-layout — documentation sidebar layout
  • .mlp-btn-primary / .mlp-btn-accent / .mlp-btn-ghost — branded buttons
Custom classes use the mlp- prefix to avoid collisions with Bootstrap utilities.

JavaScript behaviors

assets/js/script.js powers:

  • Mobile menu auto-close on link click
  • Mentor / mentee directory filters
  • Matching wizard step navigation
  • Session booking + confirm/remind toasts
  • Outcomes form draft persistence (localStorage)
  • Contact validation toast, skip link, back-to-top, scroll reveal
  • Docs sidebar active section highlighting

Customization

  1. Replace copy and demo names in each HTML page.
  2. Adjust CSS variables for your brand palette.
  3. Add or remove profile cards; keep data-skills / data-focus in sync with filters.
  4. Wire forms to your backend API when you leave the static demo.
