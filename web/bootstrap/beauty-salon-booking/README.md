# Sable Room — Beauty salon booking (Bootstrap 5)

Clean, gradient-free booking site on a light background. Brand color **#34A99D**.

## Fonts

- **Roboto** — headings
- **Lato** — UI / labels
- **Open Sans** — body

## Features

- Sticky navigation with a mobile menu
- Service board with hair, color, skin, and nail filters
- Chair booking with stylist choice, date, and time slots
- Demo visits stored in `localStorage`
- Salon hours, stylists, reviews, FAQ, and contact
- Author footer with [polurus.com](https://polurus.com) and **mail.polurus@gmail.com**

## Preview locally

From the repository root:

```bash
python3 -m http.server 8080
```

Open: `http://127.0.0.1:8080/web/bootstrap/beauty-salon-booking/`
