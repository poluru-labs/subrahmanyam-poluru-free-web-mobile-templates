# Harbor Ledger — News magazine (Bootstrap)

Single-page news magazine demo for fictional **Harbor Media**.

- **Stack:** Bootstrap 5.3, Bootstrap Icons, vanilla JS
- **Fonts:** Roboto (display), Lato (UI), Open Sans (body) via Google Fonts
- **Brand:** `#0C7B93` (no gradients)
- **Prefix:** `nm-*`

## Run locally

From the repository root:

```bash
python3 -m http.server 8080
```

Open `http://localhost:8080/web/bootstrap/news-magazine/`

## Demo behavior

- Breaking ticker and lead + sidebar headlines
- Desk filters and search on the story grid
- **Read** opens an inline article panel with sample copy
- Newsletter and tip forms show toasts only
