# Helpdesk Support

A responsive customer support dashboard built with Bootstrap 5, Bootstrap Icons, Chart.js, Roboto, and Open Sans. All custom CSS classes use the `hlp-dsk-` prefix. Solid colors only.

## Run

No build step is required. From this folder’s parent directory:

```sh
python3 -m http.server 8000
```

Open `http://localhost:8000/helpdesk-support/`. Navigation uses URL hashes, so all detail views work on static hosting without server rewrites.

## Included

- Overview with date comparisons, ticket activity, category/channel charts, urgent tickets, workloads, and activity.
- Six ticket queues, search, sorting, six filters, pagination, bulk edits, and ticket creation.
- Ticket details with public replies, internal notes, demo attachments, properties, customer details, SLA deadlines, and escalation.
- Agent cards, team membership and availability editing, performance tables, and workload charts.
- SLA monitoring with trends, breaches, approaching deadlines, and editable business-hour policies.
- Searchable articles with drafts, editing, preview, publishing, related articles, and feedback.
- Active, waiting, and closed live chat views with quick replies, simulated responses, assignment, and ticket conversion.
- Filtered reports and CSV export based on the ticket records.
- Workspace settings, business hours, notification preference, categories, priorities, canned replies, and confirmed demo reset.

The workspace starts with 36 tickets, 6 agents, 12 articles, and 8 conversations. Names and addresses are fictional. Changes persist under `hlp-dsk-v1` in local storage. Existing data from the previous landing page is left untouched.

## Demo behavior

Messages and notifications are simulated locally; no email or customer messages are transmitted. Attachments retain the selected file name only. There is no authentication or backend. New SLA deadlines skip closed hours and nonworking days in the workspace’s selected timezone, including daylight-saving changes. Policy changes affect new tickets. Report response and satisfaction averages exclude unmeasured values. Date filters apply to ticket creation dates; resolved trends show resolution dates for the selected ticket cohort.

Bootstrap, icons, Chart.js, and Google Fonts load from their CDNs and need an internet connection. Chart load failures display an explanatory empty state. The site provides keyboard focus indicators, native modal focus management, validation messages, reduced-motion support, responsive tables, and stacked chat panels on smaller screens.

## Validation

JavaScript syntax:

```sh
node --check assets/js/script.js
```

The interaction test uses jsdom (development only). With jsdom installed, run:

```sh
node tests/demo.cjs
```

Or point `HLP_DSK_JSDOM` at an existing jsdom installation. Tests cover all routes, seed counts, ticket workflows, bulk assignment, empty states, article publishing, chat conversion, validation, persistence, business-hour deadlines, and daylight-saving changes. Browser visual testing is not included.
