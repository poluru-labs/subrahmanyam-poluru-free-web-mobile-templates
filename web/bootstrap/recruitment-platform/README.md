# HireHarbor — Recruitment platform (Bootstrap)

Single-page recruitment product site for **Harbor Companies**. Brand color **#30497D**, no gradients, Google Fonts **Roboto** (headings), **Lato** (UI), **Open Sans** (body).

## Features

- Sticky navigation with mobile menu
- **Job listings** with department filters, search, save (localStorage), apply toasts
- Employer signup, pricing, FAQ, contact (demo toasts)
- Author footer with [polurus.com](https://polurus.com)

## Preview locally

From the repository root:

```bash
python3 -m http.server 8080
```

Open `http://localhost:8080/web/bootstrap/recruitment-platform/`
