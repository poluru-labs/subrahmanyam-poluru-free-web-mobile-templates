# Bayline Auto — Auto repair service (Bootstrap 5)

Clean, gradient-free service site on a light background. Brand color **#34A99D**.

## Fonts

- **Roboto** — headings
- **Lato** — UI / labels
- **Open Sans** — body

## Features

- Sticky navigation with a mobile menu
- Service grid with category filters and search
- Demo visit booking stored in `localStorage`
- Shop hours, technicians, reviews, FAQ, and contact
- Author footer with [polurus.com](https://polurus.com) and **mail.polurus@gmail.com**

## Preview locally

From the repository root:

```bash
python3 -m http.server 8080
```

Open: `http://127.0.0.1:8080/web/bootstrap/auto-repair-service/`
