# RxHarbor — Pharmacy e-commerce (Bootstrap)

Single-page pharmacy storefront demo for **Harbor Health**. Brand color **#BC0202**, no gradients, Google Fonts **Roboto** (headings), **Lato** (UI), **Open Sans** (body).

## Features

- Sticky navigation with cart badge (demo count in `localStorage`)
- Product catalog with category filters and search
- Add-to-cart toasts (no backend)
- Prescription transfer and contact forms (demo toasts)
- FAQ, delivery, and membership sections
- Author footer with [polurus.com](https://polurus.com)

## Preview locally

From the repository root:

```bash
python3 -m http.server 8080
```

Open `http://localhost:8080/web/bootstrap/pharmacy-ecommerce/`
