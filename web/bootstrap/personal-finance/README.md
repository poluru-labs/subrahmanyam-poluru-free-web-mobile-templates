# Clearpath — Personal finance (Bootstrap)

Single-page marketing and product demo for fictional **Harbor Households** money management.

- **Stack:** Bootstrap 5.3, Bootstrap Icons, vanilla JS
- **Fonts:** Roboto (display), Lato (UI), Open Sans (body) via Google Fonts
- **Brand:** `#9A3F3F` (no gradients)
- **Prefix:** `pf-*`

## Run locally

From the repository root:

```bash
python3 -m http.server 8080
```

Open `http://localhost:8080/web/bootstrap/personal-finance/`

## Demo behavior

- Category filters and search on the transaction table
- **Export CSV** for visible rows
- Filtered spend total (debits only)
- Signup and contact forms show toasts only
