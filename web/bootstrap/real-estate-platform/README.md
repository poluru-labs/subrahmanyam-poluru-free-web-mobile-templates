# Lotline — Real Estate Platform

A polished, responsive **property marketplace** with search filters, listing cards, agent profiles, and inquiry forms. Built for brokerages, indie shops, and listing sites.

**Marketplace:** Lotline  
**Brand:** `#44ACFF`  
**Prefix:** `ll-*`

Built with **HTML, CSS, JavaScript, Bootstrap 5, Bootstrap Icons**, Plus Jakarta Sans, and Source Serif 4.

## Template Overview

| Property | Value |
|---|---|
| Template Name | Real Estate Platform (Lotline) |
| Category | Real Estate, Marketplace |
| Framework | Bootstrap 5 |
| Interaction | Vanilla JavaScript |
| License | Free to use and customize |

## Features

- Sticky navigation with skip link and mobile menu
- Hero search: location, buy/rent, type, beds, max price
- Filter chips on the listing board
- Property cards with price, beds/baths, listing agent
- Neighborhood shortcuts that filter the board
- Agent profiles with message-to-form
- Inquiry form with listing + agent prefill, draft save
- How it works, reviews, office hours, FAQ, newsletter
- Accessible labels, semantic HTML, reduced-motion handling

## Getting Started

```bash
cd web/bootstrap/real-estate-platform
python3 -m http.server 8000
```

Open [http://localhost:8000](http://localhost:8000) in your browser.

## Customization

1. Replace brokerage name, office, and phone.
2. Update listing prices, addresses, and agents.
3. Connect the inquiry form to your CRM.
4. Adjust colors in `assets/css/style.css` (`--ll-primary` is `#44ACFF`).
