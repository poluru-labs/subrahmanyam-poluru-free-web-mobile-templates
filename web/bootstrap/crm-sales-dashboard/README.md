# Pipeline — CRM & sales dashboard

A focused sales workspace with a searchable pipeline, deal tracking, and CSV exports.

## Run

Open `index.html` directly, or from the parent directory run:

```sh
python3 -m http.server 8000
```

Then visit `http://localhost:8000/crm-sales-dashboard/`.

## Features

- Search and filter deals
- Create and advance deals with persistent browser storage
- Calculated open pipeline and stage totals
- CSV export

## Design

- Theme accent: `#635bff`
- Google Fonts: DM Sans, Plus Jakarta Sans, and Playfair Display as appropriate.
- Responsive, semantic HTML with keyboard focus states, native dialogs, and reduced-motion support.
- CSS artwork and inline SVG icons/charts; no stock images or icon CDN required.
- Each folder is standalone with its own CSS and JavaScript. No package install or build step.

## Demo behavior

Names and content are fictional. Forms save to localStorage and do not send messages. Refreshing preserves saved state when browser storage is available. Clear this site's storage in your browser to reset. Avoid entering real sensitive information. Google Fonts require internet access; system fonts provide an offline fallback.
