# Flare — Hotel Booking

A polished, responsive **hotel and resort website** with room listings, availability search, amenities, and reservations. Built for boutique hotels, coastal resorts, and hospitality brands.

**Property:** Flare  
**Brand:** `#F62440`  
**Prefix:** `fl-*`

Built with **HTML, CSS, JavaScript, Bootstrap 5, Bootstrap Icons**, Cormorant Garamond, and Figtree.

## Template Overview

| Property | Value |
|---|---|
| Template Name | Hotel Booking (Flare) |
| Category | Hotel, Resort, Hospitality |
| Framework | Bootstrap 5 |
| Interaction | Vanilla JavaScript |
| License | Free to use and customize |

## Features

- Sticky hotel navigation with skip link and mobile menu
- Dark gulf-coast hero with keys / pools / rating snapshot
- Availability search: check-in, check-out, guests, room type
- Filterable room listings (rooms, suites, bungalows) by occupancy
- Amenity grid: pool, spa, dining, fitness, beach, concierge, kids club, parking
- Dining and spa cards
- Reservation form with room pick, dates, guest stepper, occasion, local draft
- Guest reviews, hours, map panel, FAQ, newsletter
- Accessible labels, semantic HTML, and reduced-motion handling

## Sections

1. **Hero** — property identity and date search
2. **The Stay** — story and property metrics
3. **Rooms** — Garden King, Ocean Queen, Family Suite, Penthouse, Dune Bungalow, Accessible King
4. **Amenities** — what comes with the key
5. **Dining & spa** — Ember Room, Tide Spa, boardwalk bar
6. **Reservations** — stay request form
7. **Reviews** — guest notes
8. **Visit** — hours, address, map panel
9. **FAQ** — stay policies

## Getting Started

```bash
cd web/bootstrap/hotel-booking
python3 -m http.server 8000
```

Open [http://localhost:8000](http://localhost:8000) in your browser.

## Customization

1. Replace the property name, story, contact details, and hours.
2. Update room names, rates, occupancy, and amenity lists.
3. Swap staff biographies (Maya, Kavya, Arjun, Anika Poluru).
4. Connect the booking form to your reservation system.
5. Adjust colors in `assets/css/style.css` (`--fl-primary` is `#F62440`).
