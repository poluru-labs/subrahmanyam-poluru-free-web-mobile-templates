# PoluruCare — Modern Telehealth Clinic Platform

A comprehensive, responsive healthcare and telemedicine web template built with Bootstrap 5, featuring interactive appointment scheduling, doctor profiles, patient services, live symptom triage, insurance verification, virtual consultation room simulator, and interactive FAQs.

## 🌟 Key Features

- **Brand Styling**: Custom medical-grade theme with primary brand color `#780C28` (Crimson Burgundy).
- **Google Popular Fonts**: Typography powered by `Plus Jakarta Sans` (headings) and `Inter` (body).
- **Interactive Doctor Directory**:
  - Filter by medical specialties (Cardiology, Pediatrics, Mental Health, Dermatology, Primary Care).
  - Doctor profiles featuring **Dr. Subrahmanyam Poluru, MD**, **Dr. Subbu Poluru, MD**, **Dr. Subra Poluru, DO**, **Dr. Priya Subbu Poluru, MD**, **Dr. Ananya Poluru, MD**, and **Dr. Arvind Subra, MD**.
  - Modal bio preview with qualifications, languages, ratings, and instant booking hooks.
- **Smart Appointment Scheduling Wizard**:
  - Multi-step interactive booking form (Service & Physician -> Patient Details -> Review & Confirm).
  - Dynamic slot picker and live visit price calculator with insurance copay display.
  - Generates real-time booking confirmation codes with direct access to virtual waiting rooms.
- **Interactive Symptom Triage & Matcher**:
  - Patient symptom chip selector that recommends the exact specialist and real-time wait times.
- **Virtual Exam Room Simulator**:
  - Interactive HD video room demo with microphone mute/unmute, camera toggle, and doctor feed simulation.
- **Insurance Eligibility Checker**:
  - Real-time simulated verification widget for major insurance carriers (Aetna, BCBS, Cigna, UHC, Medicare).
- **Interactive FAQ Accordion**:
  - Real-time search filter and category buttons (General, Prescriptions, Insurance, Privacy/Tech).
- **Patient Portal Access**:
  - Quick sign-in modal for electronic health records, active prescriptions, and visit history.

## 🚀 Technologies Used

- **HTML5 & CSS3** (Custom design tokens and CSS variables)
- **Bootstrap 5.3.3**
- **Bootstrap Icons 1.11.3**
- **Vanilla JavaScript** (Zero external dependencies)
- **Google Fonts**: Plus Jakarta Sans & Inter
