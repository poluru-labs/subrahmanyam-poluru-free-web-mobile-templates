## 🎨 Design System

### 🎨 Color Palette
```css
Primary Colors:
├── Orange (Brand):     #ff914d  /* Call-to-action, highlights */
├── Dark Blue:          #2c3e50  /* Headers, primary text */
├── Blue Gradient:      #34495e  /* Backgrounds, depth */
└── Light Gray:         #f8f9fa  /* Section backgrounds */

Semantic Colors:
├── Success:            #28a745  /* Form validation, success states */
├── Danger:             #dc3545  /* Error states, warnings */
├── Text Gray:          #545454  /* Body text, descriptions */
└── Light Text:         #6c757d  /* Secondary text, captions */
```

### ✏️ Typography
- **Primary Font**: Roboto (Google Fonts)
- **Font Weights**: 100, 300, 400, 600, 700, 800
- **Base Size**: 16px (1em)
- **Line Height**: 1.80857 for optimal readability

### 📱 Responsive Design
| Breakpoint | Range | CSS Units | Target Devices |
|------------|-------|-----------|----------------|
| **Mobile** | ≤ 576px | em-based | Phones |
| **Tablet** | ≤ 768px | em-based | Tablets, small laptops |
| **Desktop** | ≥ 992px | em-based | Desktops, large laptops |
| **Large** | ≥ 1200px | em-based | Large monitors |

### 🎭 Animation & Effects
- **Transitions**: 0.3s ease for smooth interactions
- **Hover Effects**: Transform, box-shadow, color changes
- **Loading States**: Smooth fade-ins and transforms
- **Gradient Animations**: 20s float animation for backgrounds

## ⚙️ CSS Architecture

### 🏗️ Enhanced Structure
The CSS is organized with modern best practices:
- **Em Units**: All measurements converted from px to em for better scalability
- **Shorthand Properties**: Optimized CSS with combined properties
- **Alphabetical Order**: Properties organized alphabetically for maintainability
- **Comprehensive Documentation**: Detailed comments and style guide

### 🔧 CSS Organization
```css
/* Main Sections */
├── Base Styles (html, body)
├── Header & Navigation (logo, menu)
├── Hero Banner Section (main banner)
├── Statistics Section (stats display)
├── Section Headers & Typography
├── Services Section (cards, features)
├── About Section (company info)
├── Content Image Header (page headers)
├── General Content Sections
├── Address & Contact Section
├── Site Footer
├── Client Logos Section
├── Breadcrumb Navigation
├── Contact Page Components
├── Form Elements & Input Styles
└── Responsive Design (media queries)
```

### 🎯 Custom CSS Classes
| Class | Purpose | Example Usage |
|-------|---------|---------------|
| `.ftpl-service-card` | Service card styling | Service showcase cards |
| `.ftpl-content-img` | Hero section backgrounds | Page headers with images |
| `.ftpl-text-logo` | Text-based logo styling | Brand text animation |
| `.ftpl-breadcrumb` | Navigation breadcrumbs | Page navigation |
| `.ftpl-stat-item` | Statistics display | Number counters |
| `.ftpl-section-divider` | Section separators | Orange divider lines |
