About Forge Athletic

A Bootstrap gym operations dashboard for club managers: members, trainers, classes, check-ins, and memberships.

What it’s for

Forge is a static demo of a downtown club desk. Use it as a starting point for a gym CRM, class booking board, or front-desk kiosk. Copy lives in HTML; tokens live in assets/css/style.css under the gxd- prefix.

Built with Bootstrap 5, Bootstrap Icons, Barlow, and a small vanilla JS file for filters, the check-in form, and toasts.
