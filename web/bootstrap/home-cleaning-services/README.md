# Brightfold — Home cleaning services (Bootstrap)

Fictional Austin cleaning demo: service filters, saved plan, and local booking requests.

**Brand:** `#FEFAF3` · **Fonts:** Roboto, Lato, Open Sans

## Preview

From the repository root:

