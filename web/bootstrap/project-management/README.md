# PlanHarbor — Project management (Bootstrap)

Single-page project management product site for **Harbor Labs**. Brand color **#030164**, no gradients, Google Fonts **Roboto** (headings), **Lato** (UI), **Open Sans** (body).

## Features

- Sticky navigation with mobile collapse
- **Kanban demo**: project filters, search, advance tasks between columns, column counts
- Features, teams, pricing, trial signup, FAQ, contact (demo toasts)
- Author footer with [polurus.com](https://polurus.com)

## Preview locally

From the repository root:

```bash
python3 -m http.server 8080
```

Open `http://localhost:8080/web/bootstrap/project-management/`
