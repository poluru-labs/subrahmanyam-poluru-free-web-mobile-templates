# Keelframe — Construction contractor (Bootstrap)

Fictional Austin general contractor demo: services, project board with filters, shortlist, and local quote requests.

**Brand:** `#D92C54` · **Fonts:** Roboto, Lato, Open Sans

## Preview

From the repository root:

```bash
python3 -m http.server 8770
```

Open: `http://127.0.0.1:8770/web/bootstrap/construction-contractor/`
